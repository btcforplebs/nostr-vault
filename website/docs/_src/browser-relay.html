The basics

What the browser vault is

The browser vault keeps your notes like any vault, but it runs inside a web page, at nostrvault.app/relay/. It stores notes in the browser's own storage on that device and joins the mesh, so your own devices can reach it by its key. New to the mesh? Read The mesh first.

The page keeps no Nostr key of yours. You sign once to show which account is yours, and the key you sign with is not kept. Your notes arrive already signed, and the page checks each signature. A good spot for it is an old phone or tablet on a charger.

Set it up

Pair your iPhone with the page

  1. On your iPhone, open Mesh and turn the mesh on. Under This Device, tap Copy. That's the phone's mesh address.
  2. On the device that will run the page, open nostrvault.app/relay/. Paste the address into the box under the Mesh heading (one address per line).
  3. Show the page which Nostr account is yours by signing once: tap Sign with extension, or paste an nsec, an ncryptsec (with its password below) or a bunker:// link and tap Sign with key. The key signs one proof and isn't saved anywhere. A typed npub is refused ("An npub can't sign."), because anyone can type an npub. Without a signed account the page turns your notes away and keeps 0. Forget account clears it.
  4. Tap Save owners. The page reloads.
  5. Tap Start mesh. The status's first line shows the page's own mesh address. There's no Copy button, so select the address and copy it.
  6. On the iPhone, go to My Devices → Add a device. Under Paste instead, paste the page's address, tap Use, and pick Browser vault.

The phone then connects for the page. If it doesn't, open the page's entry in My Devices and tap Connect this phone. Copy this phone's mesh address is there too.

A link of the form nostrvault.app/relay/#owner=npub1… also adds an owner. The npub in it is the phone's mesh address (from This Device), not your Nostr account. The page asks you to confirm each address first, because an owner can write to the page and read everything on it. Only accept your own.

What it does

What it keeps and serves

  • Your new notes. While the iPhone app is open, each new note you post also goes to the page. Send my latest notes sends your 20 most recent notes from the phone. The result line says how many the page kept. In this testing build, check that number: if it says 0 kept, the page did not take your notes.
  • Checked notes only. The page checks each note's signature and turns away notes from authors it isn't set up for.
  • Owners only, for notes. The page serves notes on the mesh only to the addresses saved as owners. Anyone else asking for notes is dropped without an answer.
  • A public photo door. Like the apps, Start mesh also opens a public photo door on the mesh to anyone, and it answers only for photos that a public note names.
  • Photos, read only. Under Show photo, you can paste a photo's fingerprint (sha256) or a .fips link and the page fetches it from a paired vault. It shows the photo only if the fingerprint matches. Photos aren't stored on the page.

The page reaches your phone through the public mesh entry points (seeds). Once both ends are connected it tries a direct link. On the iPhone, leave the middle server under Advanced on its public setting. A browser vault has no same-network route, so with None it most likely can't reach your phone at all.

Keep it awake

The screensaver

Start screensaver fills the screen with a black "relay running" view: a count, the uptime, whether the screen is kept awake (the wake lock), and whether the seed is up. Tap anywhere to leave it. After a reload it comes back on its own, and the wake lock is taken again when the tab is visible.

The count on this screen is the page's own test notes, not your notes. Report shows storage, uptime gaps and a signature self-test, if you want the details.

When it stops

When the tab closes

  • The relay only runs while the page is open and the screen is on. Closed, locked or in the background, nothing reaches it.
  • Notes the phone sends while the page is down are not queued. Tap Send my latest notes once it's back.
  • Stored notes stay in the browser and are there when you reopen the page. The page rejoins the mesh by itself after a reload, a crash or the browser putting the tab to sleep, and again when you come back to it. Stop mesh takes the page off the mesh, and it stays off, even after a reload, until you tap Start mesh.
  • The signed account is checked again on every load. One saved by an older page, from a typed npub, is dropped: sign once more.
  • The page's mesh key lives in the browser's site data. Clear that data and the page gets a new address, so pair it again.

Your devices list

In My Devices

The page shows up in My Devices as a Browser vault, the role whose job reads "Gets your new notes while this app is open." Each phone has one browser vault, whichever account is signed in; adding a new one replaces the old.

To stop sending, open its entry and tap Remove from My Devices. Anything already on the page stays there.

Android and Mac add it the same way: My Devices → Add a device, then Paste instead with the page's address, and pick Browser vault. In this build, only the iPhone app sends notes to the page.

The web app's own vault

Live Media and slow relays in the web app

The web app at nostrvault.app keeps its own vault in the browser too (This browser's copy). Two 3.2.2 changes are about it:

  • Live Media. When this browser's vault is your home vault, files your paired devices send to it show up in the Media tab while the tab is open, as New tiles. A file your media servers already list stays as it was. The web app only reads these file notes; it doesn't write them. A file that lives only on the mesh, with no https link, gets no tile.
  • A dead relay no longer slows you down. A relay that takes the connection but never answers used to hold every quote and read for about 5 seconds. Now a one-off read waits at most 1.5 seconds for a relay that isn't connected yet, a quote stops at the first good copy, and a relay that failed is skipped for a minute, then longer each time, up to 10 minutes. The dead nostr-pub.wellorder.net is gone from the default relays, so new accounts start with four.

Be candid

Limits and privacy

  • The tab must stay open. A browser can pause or close a page at any time. Not every browser can hold the screen awake; the screensaver says whether it can.
  • Storage is the browser's. The page asks the browser to keep its data, but the browser decides. Report shows whether it agreed and how much room there is.
  • Seeds see IPs. To connect, your phone joins the middle server, which sees its IP address the way any server does. The same goes for the page's device.
  • Not in your profile. The page isn't listed in your profile, and its mesh key is its own, never your Nostr key.

The browser vault is early. Treat it as an extra copy of your notes, not your only one.
