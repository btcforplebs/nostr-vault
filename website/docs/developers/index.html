    • NIP-F1 and the mesh

    For developers

    Build the mesh into your client

    The mesh address is one new entry form, fipsmesh://<npub>/, in lists you already use: the media server list (kind:10063) and, later, the relay list (kind:10002). No new event kinds. Requests are plain Blossom GET /<sha256>, with the same hash check.

    A client that doesn't know the form skips it and carries on with the other servers in the list. A client that does can ask the device for the photo by its fingerprint, the same way it asks any media server, and throws the photo away if the fingerprint doesn't match.
