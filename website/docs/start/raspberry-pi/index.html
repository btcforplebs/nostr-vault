    Nostr Vault on a Raspberry Pi

    On this page

    • What to use
    • Install
    • Ports and your router
    • Keeping it healthy

    A Raspberry Pi on a shelf makes a good always-on vault: it uses little power, stays on, and your phones reach it at home and over the mesh. This page adds the Pi details to Get started on Linux.

    What to use

    • A Raspberry Pi 4 or 5. The vault is capped at 1.5 GB of memory and the mesh at 512 MB, so a model with more memory leaves room for other things.
    • Raspberry Pi OS 12 (Bookworm), 64-bit. The 32-bit system won't install: the vault needs arm64. Raspberry Pi OS Lite, with no desktop, is fine.
    • A USB SSD for the vault. A vault writes all the time. An SD card wears out and is slow; a USB SSD lasts much longer. Plug it in before you install and give its folder to nostr-vault-setup --data.
    • A wired network if you can. Wi-Fi works too.

    Install

    1. Set up the Pi with Raspberry Pi Imager, turn on SSH, and log in from your computer: ssh you@raspberrypi.local.
    2. Download …_arm64.deb from the release and install it as in Get started on Linux, with --no-install-recommends on a Pi with no desktop so it installs only the vault, not the window.
    3. Run sudo nostr-vault-setup --owner npub1… --data /media/you/ssd/nostr-vault with your account's npub and a folder on your SSD.
    4. When it's done it prints the address. Open http://raspberrypi.local:8080/ (or the IP address it printed) on your phone or computer, sign in, and pair the box with your phone: see A Linux box in My Devices.

    Ports and your router

    • The vault answers on port 8080 on your network. Pick another with sudo nostr-vault-setup --port ….
    • The engine (3355) and the mesh door (8081) listen only on the Pi itself.
    • Nothing opens a port on your router. Away from home, your own devices reach the Pi over the mesh, and the Pi answers only them.

    Keeping it healthy

    • The vault starts by itself when the Pi boots. If the Pi loses power, it comes back on its own.
    • Watch it with journalctl -fu nostr-vault -u nostr-vault-mesh, or open the box's page in Settings for memory, disk and mesh status.
    • Running out of room? Plug in a bigger drive and use Move vault to… on the box's page.
    • To update, install the newer .deb the same way. Your data, owner and port stay.

    Checked against Nostr Vault 3.3.0 for Linux.
