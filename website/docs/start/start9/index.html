    Nostr Vault on Start9

    On this page

    • Install (sideload)
    • Set the owner
    • Pair your phone
    • Updates
    • Backups and restore
    • Storage

    StartOS runs Nostr Vault as a service on your Start9 server: the same box as Nostr Vault for Linux, with StartOS doing the install, backups and HTTPS. Until it is listed in the StartOS Marketplace, you install it from a file on our release.

    Install (sideload)

    1. Download the package for your server from the latest release: nostr-vault-…_x86_64.s9pk for most servers, or nostr-vault-…_aarch64.s9pk for a Raspberry Pi or another ARM server. The …-startos.sha256 file beside them lists their checksums.
    2. In StartOS, click Sideload in the top bar and drop the file in.
    3. Check the package details and click Install. StartOS warns that no key you trust signed it; confirm to go on. Keep the tab open while it uploads.

    Set the owner

    1. Open Nostr Vault under Services. It won't start until it has an owner: run the Set owner npub action and paste your account's npub (never your nsec: the box never holds your private key).
    2. Start the service and wait for both health checks, Web Interface and Mesh. Mesh says "Waiting for a device" until you pair one.
    3. Open the Web UI and sign in with the same account (a signer extension or a bunker).

    The Web UI uses your server's own HTTPS certificate. A phone or computer that opens it by its .local name or LAN address needs your server's root CA installed and trusted, as for any other StartOS service. Start9's guide covers it: docs.start9.com, "Trusting your Root CA".

    Pair your phone

    Pair from the box's page, as for any Linux box: Settings → This Box → My Devices → Add a device, scan the code with Nostr Vault on your phone, and check that both show the same four words. The steps are in A Linux box in My Devices.

    • The Show box npub action shows the box's own mesh npub (text and QR code), if you would rather add the box on your phone with Paste instead.
    • Away from home your phone reaches the box over the mesh, with no router ports opened. On your own network the box offers your phone its LAN address on UDP port 47821.

    Updates

    To update, sideload the newer .s9pk the same way; StartOS offers Update instead of Install. Your data, owner and paired devices stay. The box's own Update button points you to StartOS.

    Backups and restore

    • StartOS backups copy the whole vault except the box's mesh key (with its old npub and mesh status).
    • After a restore the box keeps its owner and makes a new mesh key, so it has a new npub. Your notes and media are all there, but your phone still knows the old box: on the phone, remove the old box under My Devices (Remove a device) and pair the box again.

    Storage

    The vault lives on the StartOS data drive. The box's Move vault to… is turned off here: StartOS owns the disk.

    Checked against Nostr Vault 3.3.0 on StartOS 0.4.2.1.
